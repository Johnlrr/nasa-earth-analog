# SIMILITUDE — the proving-ground finder

SIMILITUDE finds Earth locations that match Moon and Mars mission targets by physical fidelity,
not visual appearance. For each mission lens (traverse terrain, low-Sun navigation, aqueous
mineralogy, subsurface ice), it runs the same descriptor formula on NASA data from both worlds
and reports which test results transfer — and which never can.

## Quick start

```bash
make venv
make test
```
